Second wave: instrument search authentication, API vs data cost, identifier reuse/licensing, updated effective date and current NSE operational references. Resolved: manual ID entry can be reduced; API access is not the same as free execution/data/redistribution; tax and economic P&L differ; current domain capability is not proof of wired UI capability. Bounded unresolved: current 73992 ZIP, selected broker eligibility/terms, actual price/latency/data quality and user preferences. Stop reason: further broad searches would not change the proposed isolated UX and simulation; unresolved live prerequisites are explicitly excluded from readiness claims and scheduled for a later approved phase.

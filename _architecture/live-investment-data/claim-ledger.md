# Live data and mutual-fund intelligence claim ledger

Updated: 2026-09-07

| Claim | Source | Evidence note | Confidence | Limitation |
|---|---|---|---|---|
| Zerodha Personal API is free but excludes historical and real-time market data. | Zerodha Support, "What are the charges for Kite APIs..." https://support.zerodha.com/category/trading-and-markets/general-kite/kite-api/articles/what-are-the-charges-for-kite-apis | Personal includes order/GTT/alerts/margins/portfolio, but no historical or real-time data. Paid Connect adds WebSocket and historical candles at INR 500/month per app. | High | Pricing and plan terms can change; verify before implementation. |
| Kite Connect quote APIs provide authenticated market snapshots, and WebSocket is used for real-time streaming. | Kite Connect docs, Market quotes https://kite.trade/docs/connect/v3/market-quotes/ and WebSocket https://kite.trade/docs/connect/v3/websocket/ | Quote docs define `/quote`, `/quote/ohlc`, `/quote/ltp`; WebSocket docs define live streaming. | High | Live data entitlement depends on subscription. |
| Kite instruments are daily CSV dumps; numeric instrument tokens can be reused and should not be canonical identity. | Kite Connect docs, Market quotes and instruments https://kite.trade/docs/connect/v3/market-quotes/ | Docs recommend daily caching and exchange/tradingsymbol storage rather than numeric token identity. | High | Derivative identity needs cached historical tokens. |
| Kite access tokens expire at 6 AM next day unless invalidated earlier. | Kite Connect user docs https://kite.trade/docs/connect/v3/user/ | Access-token response attributes describe 6 AM expiry as regulatory requirement. | High | Some approved platforms can receive longer read permissions; not assumed for this app. |
| Kite API rate limits are 1 quote request/sec, 3 historical requests/sec, 10 order requests/sec and 5000 orders/day per user/API key. | Kite Connect exceptions docs https://kite.trade/docs/connect/v3/exceptions/ | Rate-limit table and order/day limit documented. | High | Limits can change and must be loaded as provider config. |
| Kite mutual-fund APIs cover Coin holdings, SIPs and fund master data; the fund symbol is the ISIN. | Kite Connect mutual-funds docs https://kite.trade/docs/connect/v3/mutual-funds/ | Docs expose `/mf/holdings`, `/mf/sips`, `/mf/instruments`; response fields include `tradingsymbol` as ISIN and last NAV fields. | High | Current page states MF order placement is constrained by bank payment. |
| AMFI latest NAV download is official daily NAV evidence, and old format remains only until 30-Sep-2026. | AMFI NAV Download https://www.amfiindia.com/net-asset-value/nav-download | AMFI page exposes latest NAV downloads and old-format sunset date. | High | AMFI says data is member-provided and does not guarantee timeliness. |
| MFAPI offers no-auth mutual-fund search and latest NAV endpoints, but should be treated as convenience, not authority. | MFAPI docs https://www.mfapi.in/docs/ | Docs list `/mf/search`, `/mf/{scheme_code}`, `/mf/{scheme_code}/latest`, no auth, and recommend caching under rate limiting. | Medium-high | Third-party service can lag AMFI or break when AMFI format changes. |
| NSE website/API data is not a safe free live data backend for this app. | NSE Terms of Use https://www.nseindia.com/static/nse-terms-of-use and NSE real-time subscription https://www.nseindia.com/static/market-data/real-time-data-subscription | Terms restrict copying, caching, scraping and use for virtual trading/simulation; real-time feed is a paid subscription product. | High | Downloadable reports may be usable for private EOD tracking if terms are respected. |
| Official corporate filings are available through NSE/BSE/SEBI routing, but turning them into fundamentals is a parsing pipeline, not a simple free quote API. | SEBI corporate filings curation https://www.sebi.gov.in/curation/corporate_filings.html and NSE financial results https://www.nseindia.com/companies-listing/corporate-filings-financial-results | SEBI routes users to financial results, shareholding and other filings; NSE supports financial results and XBRL conversion. | High | Current ratios still need price, share count and normalization logic. |
| Upstox currently documents free trading and market-data APIs and has a fundamentals API by ISIN. | Upstox API overview https://upstox.com/developer/api-documentation/api-overview, instruments https://upstox.com/developer/api-documentation/instruments/, key ratios https://upstox.com/developer/api-documentation/get-key-ratios/ | Docs expose analytics token, instrument files, and ratios such as P/E/P/B/ROE/ROCE. | Medium-high | This is outside the user's preferred Zerodha broker and still requires account/token/terms review. |

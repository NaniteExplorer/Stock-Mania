Foundations

Four scales govern every control on this page: a five-step height rhythm, a six-step radius set, a five-step border ladder, and one transition. Nothing below picks a value outside them. Each specimen can be pinned Light or Dark in place — the control is judged against both grounds without leaving the page.

Control height rhythm

24 / 28 / 32 / 36 / 40 — a 4px step, so any two controls share a baseline
--h-xs
--h-sm
--h-md
--h-lg
--h-xl

Why 32px is the default. The table row at Compact density is 32px. A button, an input, a select and a badge row all resolve to 32px too, so a control dropped into a table cell does not change the row height. 24px exists only for controls that live inside another control (a chip's clear button, a stepper arm). 40px is the mobile touch size — below 640px every interactive control in a .touch region is promoted to it.

Radius set

Radius is bound to control height, not chosen per component
--r-1 2px
--r-2 3px
--r-3 4px
--r-4 6px
--r-5 8px
--r-pill

Radius follows height. A single 3px radius on a 40px control reads as a cut corner rather than a curve, because the eye judges the arc against the edge it interrupts. So: controls ≤32px take --r-2 3px, controls ≥36px take --r-3 4px, panels take --r-4 6px, modals and sheets --r-5 8px, elements nested inside a control (checkbox, chip close, swatch) take --r-1 2px, and status dots alone take --r-pill. Table cells stay at 0.

Correction 1 — the inherited control border failed WCAG 1.4.11. Design-research §1.4 assigns --border-strong (light #B9C2CC, dark #343C45) to form-control boundaries and claims it meets the 3:1 non-text minimum. Measured, it is 1.80:1 in light and 1.60:1 in dark — an input's edge was effectively invisible as a boundary. A new token --border-control replaces it: light #808C9A at 3.42:1 on surface and 3.21:1 on canvas, dark #64707E at 3.54:1 on surface and 3.25:1 on raised. --border-strong survives only as decorative container chrome, renamed --border.

Correction 2 — the dark container hairline was invisible. In a system where borders carry all elevation, dark --border at --n-800 #232A31 measured 1.23:1 against the #13181D surface, so panels had no visible edge. Moved one step to --n-700 #343C45 (1.60:1), which reads as a hairline without becoming a rule.

new ramp steps --n-450 #808C9A (light control border) · --n-775 #2A323A (dark pressed surface)

Two more token corrections

Both found by measuring, not by eye

Correction 3 — muted caption on a subtle fill. --fg-muted #64707E on the old light --bg-subtle #EFF2F5 measured 4.49:1 — a hair under AA. Rather than darken every caption, --bg-subtle moved from #EFF2F5 to #F2F5F8, which lifts it to 4.61:1 and incidentally makes the subtle fill read as a tint of the canvas rather than a third grey.

Correction 4 — disabled text, and why contrast is not a state channel. The inherited --fg-disabled measured 2.93:1 (light) and 2.31:1 (dark). WCAG exempts inactive controls, but relying on faintness alone is the lazy version of this state. Raised to #7C8896 (3.61:1) and #5C6875 (3.14:1), both still a clear step below --fg-muted — and disabled is carried by the fill and border instead: surface drops to --bg-subtle, the border weakens from --border-control to --border, the inner highlight is removed so the control sits flat, and the cursor becomes not-allowed.

The focus ring, and why it has a gap

2px accent, 2px offset, on every interactive element
Outside a row Inset, in a tight row

Two offsets, one ring. Standalone controls take outline-offset:2px: the 2px gap renders in whatever surface sits behind, which separates the ring from the control's own border so the two never read as one thick edge. Controls packed into a tight row — table headers, menu items, segment buttons, calendar days — take outline-offset:-2px instead, so the ring sits inside the hit area and cannot be clipped by a neighbour or a scroll container. The accent measures 5.16:1 on the light surface and 5.79:1 on the dark one, both well past the 3:1 non-text minimum. Input shells focus at offset:1px and simultaneously swap their border to the accent, so the boundary and the ring agree.

ring 2px solid var(--accent) · offset 2px standalone / −2px packed / 1px input shells
light #4F62D8 5.16:1 on #FFFFFF · dark #7D8CEA 5.79:1 on #13181D

Tracking is corrected per size, not inherited. Inter's default tracking is tuned for body copy; at 24px and above it opens up. Pressed shifts the label, not the button. On :active the button's children translate 0.5px down while the box stays put — a button that moved as a whole would break alignment with the controls beside it. The inner highlight is removed at the same moment, so the control reads as seated rather than raised.

Elevation and the inner highlight

The highlight follows the light source, so it inverts between themes
Floating layer · --shadow-pop

Light has no room above white. A 1px white inner highlight on a #FFFFFF button is invisible, so in the light theme the raised control is seated with a 1px bottom inset instead — inset 0 -1px 0 rgb(19 24 29 / .07) — which reads as the control resting on the surface. In dark, the surface has room above it, so the token flips to a true top highlight, inset 0 1px 0 rgb(255 255 255 / .055). One token name, --inner-hl, two opposite values; filled controls take --inner-hl-2 at roughly double strength because a saturated fill swallows a faint edge.

shadows only on genuinely floating layers — menu/popover 0 4px 12px, modal/sheet 0 16px 48px. Everything else is a 1px border.

Motion budget

90ms, colour and transform only

Every transition in this kit is 90ms cubic-bezier(.2, 0, .38, 1) and animates only background-color, border-color, color, box-shadow and transform. Nothing animates width, height, opacity-on-load or position. Under prefers-reduced-motion all durations collapse to 1ms and the two spinners stop rotating, becoming a static dotted ring that still reads as busy beside aria-busy="true".

--t-fast 90ms (state changes) · --t 110ms (bar and fill widths) · --ease cubic-bezier(.2,0,.38,1)

Buttons

Five variants, three sizes, nine states. Every state is a considered change — a surface step, a border step, an inner-highlight removal — never a hue swap. Hover and press the specimens; they are live.

Loading keeps the button's width. The label is set to visibility:hidden rather than removed, so it still occupies its box and the spinner is absolutely centred over it. Data-table row · seven states

Compact 32px rows; selection is an inset bar, not a fill
HoldingPlatform Market valueUnrealised Price state

Why selection is a bar and not a fill. A filled selected row competes with the hover fill and with the expanded row's fill, so three states collapse into one visual idea. A 2px inset accent bar on the leading edge is unmistakable, survives on both themes, costs no contrast against the text, and still lets the row show hover underneath it. Zebra striping is absent by design — a 1px bottom rule per row plus hover does the same job without fighting column groups.

Hand-authored inline SVG on a 16×16 grid at a single 1.3px stroke, round caps and joins. No icon font, no library. Every path lands on a half-pixel so the 1.3px stroke renders crisp at 16px without hinting.

One stroke weight, scaled by the viewBox. The stroke is declared at 1.3 units in a 16-unit box, so at 14px it renders 1.14px, at 16px 1.3px and at 20px 1.63px. Optical weight therefore stays constant relative to the icon's own size — the alternative, a fixed 1.5px stroke at every size, makes 14px icons look heavy and 20px icons look thin. Terminals and verticals land on the 4px grid shown above; only the diagonals and the chart paths break it, because snapping a trend line to the grid would make it a staircase.

Domain

Asset classes and account kinds

Drawn from the instrument, not from a metaphor. Equity is an OHLC bar, because that is how a listed price is actually quoted. ETF is a basket of three bars inside one frame — a traded wrapper around holdings. Mutual fund is the same basket without the frame, since it is not exchange-traded. Gold is a single cast ingot and silver is two thinner ones, which distinguishes them without colour. SGB carries the bond's seal over the ingot. FD is a clock in a rounded vessel: a deposit that matures.

one 28px rhythm across the whole bar — the view segmented control, the search shell, every facet button, the density control, Columns and the Export split are all --h-sm, so the toolbar has a single top and bottom edge rather than a ragged one

The chip row is a second band, not a wrap. Active filters and the sort chip sit on --bg-subtle below the controls, separated by a hairline. Letting them wrap into the toolbar makes the bar's height jump as filters are added and removed; a dedicated band keeps the control row fixed and gives the row count a stable home on the right, where a live region announces it.
